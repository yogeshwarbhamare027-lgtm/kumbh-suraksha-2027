Mathematical Model
FERI(Zj) = Σ wi × μij

Contributionij (%) = (wi × μij / Σk(wk × μkj)) × 100

μij is automatically derived from the contribution percentage and scaled to the range 0–1.

Mathematical Model Explanation

The FERI (Fuzzy Environmental Risk Index) represents the overall environmental and public-health risk level for a particular zone. It is calculated by multiplying the weight of each parameter by its fuzzy membership value and then summing the results.

wi = weight assigned to parameter i. The weight represents the relative importance of that parameter in the overall risk calculation.

μij = fuzzy membership value of parameter i for zone j. This value represents the degree to which that parameter contributes to the risk in the selected zone and remains between 0 and 1.

FERI(Zj) = the total FERI score of zone j, obtained by summing all weighted fuzzy membership values (wi × μij) for the parameters included in the model.

Contributionij (%) shows how much parameter i contributes to the total FERI score of zone j. It is calculated by dividing the weighted contribution of that parameter by the sum of all weighted parameter contributions for the same zone and multiplying the result by 100.

The contribution percentage is then used to automatically derive the corresponding fuzzy membership value μij, which is scaled to a value between 0 and 1. Therefore, higher membership values indicate greater risk contribution from that parameter.

In this model, the final FERI value is interpreted using the following proposed risk thresholds: 0.00–0.25 = Low, 0.25–0.50 = Moderate, 0.50–0.75 = High, and 0.75–1.00 = Very High. These thresholds are proposed research-model thresholds and require validation before operational public-health use.
